| Severity | Finding |
|---|---|
| High | Snapshot install persists the log purge before the state-machine install completes; a crash leaves an unrecoverable state. |
| Medium | Documented-valid `PartialSuccess(None)` panics the leader in debug builds. |
| Medium | A state-machine worker panic (apply or install) leaves the caller hanging while RaftCore stays alive. |
| Medium | `snapshot_max_chunk_size = 0` sends zero-byte snapshot chunks forever. |
| Low/Medium | `purge_batch_size = 0` underflows in `calc_purge_upto()`. |
| Low/Medium | Blocking `add_learner()` returns `Ok` after a leadership change before the learner catches up. |
| Low/Medium | `heartbeat_interval = 0` leaves the tick loop unthrottled. |
| Low/Medium | `install_snapshot_timeout = 0` makes every snapshot RPC time out immediately. |
| Low/Medium | `QuitLeader` leaves replication tasks running; a deposed leader keeps sending a snapshot. |
| Low/Medium | `Raft::shutdown()` returns while the state-machine worker can still modify the store. |
