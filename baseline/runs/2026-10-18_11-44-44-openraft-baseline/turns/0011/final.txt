| Low/Medium | `heartbeat_interval = 0` is accepted and leaves the tick loop unthrottled. |
| Low/Medium | `install_snapshot_timeout = 0` is accepted and every snapshot RPC times out immediately. |

The new F7 evidence: `Config::build` accepts `--install-snapshot-timeout=0`, and the chunked transport with a zero `RPCOption` hard TTL fails the install RPC immediately:

```
zero install-snapshot timeout result is_err=true, calls=1
```

Reproduction: `cargo test -p openraft --lib --features generic-snapshot-data audit_install_snapshot_timeout_zero -- --nocapture`; the test is in `network/snapshot_transport.rs` and included in the patch. The report recommends rejecting a zero install timeout or clamping it to a minimum.
