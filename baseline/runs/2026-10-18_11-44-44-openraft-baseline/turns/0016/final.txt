F9’s reproducer is [t11_shutdown_sm_worker.rs](/home/nitro/Desktop/consensus-assurance/baseline/runs/2026-10-18_11-44-44-openraft-baseline/work/tests/tests/audit/t11_shutdown_sm_worker.rs). A delayed snapshot install is pending when `shutdown()` is called; after shutdown returns, the worker completes the install and the store changes:

```
SM applied after shutdown: before=None, after=Some(LogId { leader_id: LeaderId { term: 1, node_id: 0 }, index: 6 }), snapshot=LogId { leader_id: LeaderId { term: 1, node_id: 0 }, index: 6 }
```

`Raft::shutdown` joins RaftCore but leaves the SM worker’s `JoinHandle` detached, so a caller that closes or reuses the store can race with an in-flight apply/install. The report records the lifecycle basis and remediation (join or cancel the worker before returning).
