## Finding 1 — `cluster.EnsureSamePeers` compares a stale configuration snapshot (`testing.go:689`)

`testing.go` is a shipped, non-`_test.go` package file, so its helpers are part of the library surface (`MakeCluster` is exported and its value exposes `EnsureSamePeers`). The helper is a bounded polling loop that is supposed to re-read every node's configuration until they match. But it snapshots the first node's config **once, before the loop**, and never refreshes it:

```go
peerSet := c.getConfiguration(c.rafts[0])   // read ONCE
CHECK:
	for i, raft := range c.rafts {
		...
		otherSet := c.getConfiguration(raft)   // re-read, but compared to the frozen peerSet
		if !reflect.DeepEqual(peerSet, otherSet) { ... goto WAIT ... }
	}
```

If `c.rafts[0]` is the node catching up (the common case in `TestRaft_HasExistingState`, where node 0 is a follower), the recalculated `otherSet` advances to the new config while `peerSet` stays frozen at the old one — the loop can never converge, and the helper fails after the 5s `longstopTimeout` even though the cluster is fine.

Executed evidence, not suspicion:

- Instrumenting the exact test to dump state right before the failure showed **all three nodes fully converged** (`state=Follower/Leader last=3 commit=3 applied=3 latestCfgN=3`) while the assertion still printed the old 2-voter `peerSet` — proving the compared value was stale.
- Unmodified tree: 4–9 failures per 40 runs (`.runtime/audit/diag_inst.log`, `diag_orig.log`, `stress_hasstate2.log`).
- One-line causal fix — move `peerSet := c.getConfiguration(c.rafts[0])` inside the `CHECK:` block — yields **0/60** and **0/40**, everything else unchanged.

Self-contained repro: `.runtime/audit/repro_ensurepeers.sh` (this run: unmodified 6/40 failures vs fixed 0/40, with the applied change printed).

Alternatives I checked and rejected: load/slowness (present at low load, and the dump shows convergence at failure), instrumentation perturbation (the causal change is only *where* the read happens), and injected sabotage (the file is byte-identical to authenticated upstream — see below).
