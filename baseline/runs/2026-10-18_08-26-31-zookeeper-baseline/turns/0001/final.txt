Audit completed. Four concrete, locally reproducible defects are documented in [report.md](/home/nitro/Desktop/consensus-assurance/baseline/runs/2026-10-18_08-26-31-zookeeper-baseline/work/report.md).

1. **Snapshot fallback leaks rejected state.** When a newer snapshot is rejected and an older valid snapshot is loaded, [DataTree.deserialize](/home/nitro/Desktop/consensus-assurance/baseline/runs/2026-10-18_08-26-31-zookeeper-baseline/work/zookeeper-server/src/main/java/org/apache/zookeeper/server/DataTree.java:1345) leaves the rejected snapshot’s ephemerals, containers, and TTLs behind; `SerializeUtils.deserializeSnapshot` also leaves its sessions in the caller’s map. Repro: `repro/snapshot_retry/SnapshotRetryRepro.java`.

2. **Documented snapshot-limit disable value crashes the sync thread.** With `-Dzookeeper.snapSizeLimitInKb=0`, [SyncRequestProcessor.resetSnapshotStats](/home/nitro/Desktop/consensus-assurance/baseline/runs/2026-10-18_08-26-31-zookeeper-baseline/work/zookeeper-server/src/main/java/org/apache/zookeeper/server/SyncRequestProcessor.java:150) computes `% 0`, throwing `ArithmeticException` and terminating `SyncRequestProcessor`. The docs explicitly say non-positive values disable the feature. Repro: `repro/snapsize_zero`.

3. **Oracle revalidation can spin forever.** In [QuorumOracleMaj.revalidateOutstandingProp](/home/nitro/Desktop/consensus-assurance/baseline/runs/2026-10-18_08-26-31-zookeeper-baseline/work/zookeeper-server/src/main/java/org/apache/zookeeper/server/quorum/flexible/QuorumOracleMaj.java:122), the inner index is never incremented and a failed `tryToCommit` only exits the inner loop. The outer loop repeats without progress. Repro: `repro/oracle_revalidate`.

4. **Election oracle path can bypass majority quorum with 3+ voters.** [FastLeaderElection.receivedLeadingNotification](/home/nitro/Desktop/consensus-assurance/baseline/runs/2026-10-18_08-26-31-zookeeper-baseline/work/zookeeper-server/src/main/java/org/apache/zookeeper/server/quorum/FastLeaderElection.java:1185) checks `getNeedOracle()` without checking voter count. With three voters and one vote, the production method returned a vote for the candidate; majority quorum should require two votes. Repro: `repro/oracle_fle`.

The captured implementation was not modified. The broad server and quorum suites passed; the sole quorum-suite error was an external-DNS lookup of `google.com` in the isolated sandbox, not an implementation failure. Exact commands and preserved outputs are in the report and `repro/` directories.
