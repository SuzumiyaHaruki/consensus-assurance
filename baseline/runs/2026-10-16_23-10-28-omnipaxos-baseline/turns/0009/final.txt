The stall's mechanism is now confirmed at the source *and* observed in a stalled instrumented run.

**Confirmed: a re-sent `Decide` can never take effect.** `send_decide(to, decided_idx, resend)` chooses the sequence number with `resend => get_seq_num(to)` — the counter already in use — versus `!resend => next_seq_num(to)` ([leader.rs](/home/nitro/Desktop/consensus-assurance/baseline/runs/2026-10-16_23-10-28-omnipaxos-baseline/work/omnipaxos/src/sequence_paxos/leader.rs:240)); a follower only accepts a message whose counter equals `self.counter + 1`, classifies `msg <= self` as `Outdated`, and `Outdated` is handled as `=> ()` — silently dropped, no resync ([util.rs](/home/nitro/Desktop/consensus-assurance/baseline/runs/2026-10-16_23-10-28-omnipaxos-baseline/work/omnipaxos/src/util.rs:382)). So when the StopSign path re-sends `Decide` with that follower's current counter, every resend is `Outdated` by construction and can never advance the follower's decided index. The instrumented stalled run shows exactly that, repeatedly, to the end:

```
[diag-leader pid 2] resend: … decided_idx=9 … accepted_indexes=[5, 9, 10] … stopsign_decided=true
[diag pid 3] seq: from=2 msg=(session 3, counter 1) current=(session 3, counter 1) -> Outdated
```

That stands as a defect in its own right, independent of the harness mapping, and I added the concrete fix direction (increment the counter when re-sending, or treat a stale `Decide` as a resync trigger).

**One inconsistency reported rather than smoothed over.** The instrumented *passing* runs print `follower_id=3 leader_id=2 nodes_to_stop=[1]`, which would make the panic's "Follower log" pid 3's — yet pid 3's traced `decided_idx` is 9 while that printed log reads as `decided ≤ 5`. Either the stalled run had a different role assignment (my role line did not catch a stall in 4 further attempts — all four passed in ~3 s) or the two observations are of different nodes. The raw logs are named in the report so the next run that stalls *while* printing the role line settles it in one attempt.

Finding 3 now leads with what is deterministic and confirmed — the strand-a-follower probe (5000 rounds, no load, fixed by one `reconnected(1)`) plus the resend-arithmetic defect — and separates the harness-specific uncertainty.
