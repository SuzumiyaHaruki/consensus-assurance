Raft protocol knowledge, version 2. Source: Diego Ongaro and John Ousterhout, In Search of an Understandable Consensus Algorithm, https://raft.github.io/raft.pdf, sections 5 and 6. This is candidate normative context, not an analysis result for this repository.
Candidate guarantees include election safety, log matching, leader completeness, and state machine safety. Investigate which are applicable and which code or interface responsibilities support them. Fixed membership and crash faults are not interchangeable with reconfiguration and Byzantine faults. Durable protocol state and recovery behavior require the actual storage contract. Investigate support identities, context, acceptance rules and constraints on future actions as applicable. A library may delegate persistence or application guarantees to callers. Never choose a fixed target solely from the repository name or this knowledge file.
