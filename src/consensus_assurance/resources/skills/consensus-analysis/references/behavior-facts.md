# Local behavior and semantic facts

For a selected behavior record actor, trigger, context, purpose, consumed facts and their actual producers; checks, writes, persistence, sends and callbacks; success/reject/stale/error/partial/configuration branches; external inference; existing protections; interfering events; and the smallest discriminating check.

Separate independent actors and branches whose outputs mean different things. A fact is an established assertion scoped by identity and context, not a raw variable or a mixture of possible outcomes. Observation, notification, durable completion and role transition completion are different facts. Preserve unknown establishment instead of connecting adjacent known activities directly. Do not turn code guards into normative obligations without a justified contract or explicit derivation.

Follow only actual fact dependencies across shared state, request identity, context versions, object replacement, persistence, configuration activation, recovery, reclamation and independent loops. Different event orders alone do not imply a violation. Seek alternate guards, ownership, serialization, generation IDs, persistence-before-reply, later validation and reconstruction; narrow or close suspicions explained by those mechanisms.

Use produces_fact_ids/consumes_fact_ids once. The controller derives reverse indices; there is no independent transfer-edge object. Record unknown producers/consumers in Fact.unknowns. Do not infer a guarantee from queue receipt, a progress update or an unverified caller.

Use actual source identities. Contiguous acquired subranges of one captured version can be registered without new acquisition. Text-view aliases are lookup keys, not citations. Missing source requires reading, not deletion of an evidence dependency. Retain protections and contrary evidence in the current question. Detailed history stays archived; the next workset contains only the selected fact lifecycle, obligation, source, discriminator and check plan.

When Behaviors process related inputs/responses, update the same evidence/context or serve the same consumer, compare context validity, identity correlation, invalidation, errors/partial results, durability and generation/version transitions. An independent asynchronous path updating shared evidence while the main progress path is blocked can justify focused reading. Asymmetry alone is not a defect: establish the weakest source-grounded Fact, locate its actual consumer, determine whether that consumer interprets it more strongly, then seek alternate protections. Preserve both applicable variants and unresolved responsibility.
