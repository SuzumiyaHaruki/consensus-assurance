# Local behavior and semantic facts

Describe the actual actor, trigger, context, consumed facts, guards, effects, branches, protections and asynchronous handoffs. Keep this shared implementation account separate from an individual check and its execution status.

Separate independent actors and branches whose outputs mean different things. A fact is an established assertion scoped by identity and context, not a raw variable or a mixture of possible outcomes. Observation, notification, durable completion and role transition completion are different facts. Preserve unknown establishment instead of connecting adjacent known activities directly. Do not turn code guards into normative obligations without a justified contract or explicit derivation.

Follow only actual fact dependencies across shared state, request identity, context versions, object replacement, persistence, configuration activation, recovery, reclamation and independent loops. Different event orders alone do not imply a violation. Seek alternate guards, ownership, serialization, generation IDs, persistence-before-reply, later validation and reconstruction; narrow or close suspicions explained by those mechanisms.

Use produces_fact_ids/consumes_fact_ids once; reverse indexes are derived. Put known weak guarantees in meaning, validity_context or durability; put check exclusions in Scope and execution status in CheckRun/feedback. Generic caution and untested cases alone are not shared unknowns. Preserve concrete counterevidence, external contract gaps and independent consumers; a local holds or excluded mode does not constrain the shared mechanism.

Use actual source identities. Contiguous acquired subranges of one captured version can be registered without new acquisition. Text-view aliases are lookup keys, not citations. Missing source requires reading, not deletion of an evidence dependency. Retain protections and contrary evidence in the current question. Map reusable relationships at natural handoffs, with sourced preserves/challenges; retain observation-specific details in execution/feedback and full history at its locators.
