# 稳定能力回归

测试在隔离副本执行，目标源码只读。真实 TLC 需要 Java、TLC_JAR 和本地 RMI 权限；mock 回复只驱动框架，不计为自主发现或实现正确性证据。

| 能力 | 当前覆盖 |
| --- | --- |
| R1 实现规格 | 七类边界、合法 unknown/externalized/N/A、多对多事实关系、聚合硬错误 |
| R2 描述性重整 | 错误草稿 → spec_refine → 拆分/新增行为与事实 → 保留未知 → 受理一致但不完整的规格 |
| R3 中间建立缺口 | 参数化 peer support/commit/apply 与 snapshot/transfer/install，未知步骤不自动补边 |
| R4 阅读预算 | 保留语义顺序、按唯一字符预算重规划或显式延期，不采用 cheapest-first |
| R5 有界证据路径 | 单主要义务、主要事实生命周期、ready 检查优先；描述发现/推导/可选重整进入真实隔离直接执行 |
| R6 直接执行证据 | 真实违反、有限通过、缺前提/观测、工具失败、语义争议、目标变化、身份/上下文关联及后果限制 |
| R7 TLC | 语法、反例、有限 holds、触达、校准、回放、检查器归因和 F1–F4 边界 |
| R8 历史视图 | 选定 2026-09-18 失败可查看；旧版本不能按新语义恢复；原始草稿不成为证据 |

R1–R5/R8 的紧凑入口是 `tests/unit/test_audit_capabilities.py`，完整前端至直接执行在 `tests/integration/test_direct_checks.py`。R6/R7 继续使用已有来源、隔离执行、共同谓词、可达性、校准、语义见证和恢复事务测试。未为 H4/H5/H7 各保留独立永久测试。

删除旧 Goal/Handoff/ActivityCoverage 和旧 wire 形状断言；历史 source-split 大录制改为最小合成参数化测试，保留不可删除实际行为行、不可改写已受理绑定、错误指针不崩溃等不变量。删除 `recorded_repair`、`snapshot_inventory.json`、`discovery_wire_failure.json`、`covered_citation_failure.json`；当前选定真实运行在 runs 原样保留；此前运行已按用户 2026-09-18 的授权清理。

合成 toy 的整文档范围按隔离副本实际长度生成，源码定位和越界测试继续使用明确范围。下游固定验证脚本有显式测试层描述性回复，不在生产 MockAgent 内兼容旧 discovery；默认工作流仍经过描述发现及 derive。测试源码和 fixture 不是 runtime 答案。
