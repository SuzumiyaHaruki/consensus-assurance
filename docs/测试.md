# 测试与本地对照

回归测试使用隔离副本；目标仓库和历史归档不改写。预置回复只验证框架串接，真实 TLC 只支持对应模型，均不能冒充自主发现或完整协议正确性证据。

保留的主要流程包括：选择 → 本地读取 → 最后一次分析；分流后按原 ID 恢复；独立意见合并且不阻塞检查；真实字段比较与模型共同性质；有限 TLC、校准和 F1–F4 边界。旧读取收费、自然语言等价判断、直接性质副本、重复 hash 和细粒度读取恢复测试已删除，没有新增跳过或 xfail。

测试入口仍在 tests/unit、tests/integration 和 tests/e2e。tests/fixtures 的录制材料仅供离线测试；新回复不接受旧字段。历史报告原文在各 runs 目录，过去测试数和行数可从 Git 历史查看。

## 执行方法

在仓库的隔离副本中执行：

```bash
PYTHONPATH=src TLC_JAR=/实际路径/tla2tools.jar /实际路径/.venv/bin/python -m pytest -q -ra
```

Paxos 局部对照使用已有发送函数、注册解码器及 full/full、short/short 正常配对。测试输入、实际事件和输出单独保存；只替换 peer 字节流，不建立网络投递或共识前史。

```bash
PYTHONPATH=src /实际路径/.venv/bin/python tests/acceptance/paxos_codec_followup.py \
  --repo /实际路径/swiftpaxos --output /新的临时输出目录
```

输出保留 snapshot.json、Go 输入、check.json、原始工具日志及 directed-followup.json；临时工作副本用完清理。该命令是人工定向实验，不调用 Agent，不计自主发现，也不创建完整协议缺陷结论。
