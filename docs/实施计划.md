# 首版实施计划：自主发现目标与有限证据闭环

本计划依据用户对默认自主探索流程的修订，替代“预先指定选举安全性，再组织检查”的实施路径。本文面向开发者阅读，不拼接为运行时 agent 指令；运行时模板和动态任务另以英文实现。

## 1. 交付目标

用户只提供目标仓库或目标配置，系统即可在有限阅读和执行预算内，从仓库材料与协议知识中识别候选目标，说明规范依据和适用条件，自主选择一个切入点，分解义务、建立映射、构建有限模型、执行工具，并据结果继续调查或诚实报告受阻。

一次运行只深入一条分析链，不要求枚举全部目标，不要求发现真实缺陷。候选集合可随反馈增加、修订或撤回，停止时仍保留未探索区域及未完成义务。

真实模型检查支持模型范围内的结论；实现测试支持实际执行路径；二者都不自动构成整体协议正确性证明。

## 3. 三种入口与来源标记

| 入口 | 目标来源 | 用途 |
| --- | --- | --- |
| 默认自主探索 | agent 根据实际材料提出并选择 | 产品主流程及自主能力验收 |
| 可选定向分析 | 用户给出问题或范围限制 | 深入特定问题，仍需验证依据和映射 |
| 固定回归案例 | 测试夹具预先指定 | 检查模型执行、状态处理、反例反馈和报告 |

`analysis_mode` 与 `agent_backend` 分开记录：mock 可以模拟自主探索流程，但不能变成真实发现证据；真实 agent 运行固定案例也不能计为无目标输入的自主验收。模型另记 `agent_generated`、`preset`、`imported` 或 `isolated_mutation` 来源。

## 4. 工作流调整

### 4.1 建立受限材料集合

先识别实际仓库、构建信息和代码结构，建立文件与符号索引，再按预算读取设计文档、接口契约、测试断言和实现区域。实现适配器提供材料发现与符号定位能力，不先返回某一性质的绑定列表。

材料记录保留快照、文件、符号、范围和内容出处。区分“发现文件”“读取片段”“送给 agent 的材料”和“尚未探索”。扫描过文件名不算理解其内容。读取均受路径、文件类型、大小与敏感信息排除规则约束，目标中的指令文件不能覆盖系统规则。

首版默认使用本地材料及随包提供的有出处协议知识；不静默联网补齐缺失规范。

### 4.2 发现与比较候选目标

通用英文发现任务要求 agent 输出：初步实现理解、候选目标、各目标的预期行为依据、实际代码观察、适用假设、相关区域、未确认项和材料冲突。协议候选性质只是参考资料，不能自动转成已发现目标。

目标的规范性依据与实现行为观察分开：文档声明、接口要求、测试断言、协议知识、agent 推测分别记录。只有代码现状而无规范依据时，允许记录待确认假说，不能报告为已经确认适用的性质。

输出校验核实引用是否存在、引用范围是否位于实际读取材料、目标标识是否唯一。结构校验只能证明格式和引用可定位，不能证明 agent 的语义解释正确。

### 4.3 选择目标并分解义务

agent 从有依据的候选中自主选择一个，解释其重要性、现有证据缺口、可执行检查方式和预算适配性，同时记录其他候选暂不深入的理由。无需虚构精确置信度或打分。

随后围绕目标提出义务、环境条件、共同依赖和替代机制，并请求所需的进一步代码片段。映射到实际符号、分支、状态更新、持久化、恢复和错误路径。调度层检查预算与工具能力，不暗中把选择改成有预置模型的性质。

### 4.4 构建并执行模型

默认路径支持 agent 产生新的有限 TLA+ 模型及结构化元数据，而不局限于在预置模板中选择。生成模型必须说明初始状态、变量、动作、故障语义、边界、抽象行为、待检查性质及关键约束的来源。

预置模板可以明确标记后复用，但不能倒过来限定可选目标。无法在现有工具与预算内建立合适模型时，记录具体能力缺口。

工具命令由适配器组织，模型输出不提供任意 shell 执行能力。生成模型的文件路径、可访问模块和输出目录受控；不允许通过外部模块执行任意宿主操作。需要检查模型是否把待检查义务作为假设、是否用状态过滤隐藏违规状态；这类审阅保留不确定性，不宣称自动完成抽象正确性证明。

### 4.5 反馈与问题结构修订

反馈至少分为模型错误、模型反例、映射缺口、假设缺乏依据和检查范围内无反例。反馈任务读取结构化记录，不读取中文报告作为指令。

允许提出有类型的修订：增加或撤回候选目标、改写义务分解、调整映射、修订假设、生成新模型版本，以及在预算内更换深入的切入点。每次修订说明依据、影响对象和范围变化；旧模型、失败和证据保留，关联证据重新判断适用性。

模型反例先调查可达性、调度、故障与代码对应，再尝试隔离实现测试或重放。没有实现证据不能标记实现复现；没有证据证明抽象不成立，也不能因重放失败标记伪反例。

### 4.6 停止与恢复

预算耗尽、工具受阻、材料不足或当前可执行动作结束时保存检查点与中文报告。恢复要检查代码、材料、模型、配置和工具信息，区分历史复用和新执行。不会因为运行结束而支持剩余主张。

## 5. 最小数据调整

保留 `Claim`、`Binding`、`ModelArtifact`、`CheckRun`、`Evidence`、`Finding` 和 `Relation`，增加少量直接服务工作流的记录：

| 记录 | 必需信息 |
| --- | --- |
| `MaterialRef` | 来源类别、快照、文件或资源、范围、原文、读取记录 |
| `DiscoveryRecord` | 材料集合、实现理解、候选目标引用、冲突、未探索区域、agent 执行来源 |
| `SelectionRecord` | 所选目标、选择理由、其他候选未选理由、检查策略与预算依据 |
| `RevisionRecord` | 修订对象、前后版本、理由、触发执行、范围变化与证据影响 |

`Claim` 增加结构化来源引用、规范依据和相关实现区域；保留候选身份与独立评估状态。来源类别和引用完整性由类型与普通测试检查，不新建冻结清单或额外 gate。

关系图保留共同依赖、替代路径、条件、支持、质疑和修订的区别。不因依赖节点得到局部支持就自动支持上层目标，循环关系不产生自证。

## 6. 依赖边界与资源调整

- 核心工作流只认识材料、候选、选择、义务、模型和工具接口，不认识 Raft 专属字段。
- 协议包提供带出处知识、术语、候选方向、建模方法和可复用资源。删除默认“协议匹配即生成固定待检查主张”的装配路径。
- 实现适配器负责仓库识别、通用符号/材料定位、构建测试与可用重放动作。投票专属定位器成为可调用专用能力，不限定发现范围。
- Agent 后端提供发现、细化、建模和修订的不同输出 schema，支持有限格式修复。真实 Codex 根据本机能力探测调用，沿用已授权认证，不切换付费渠道。
- TLC 后端接受通用模型制品与元数据，不认识目标名称。
- 投票模型与负例作为固定回归资源保留。非 Raft 计数器证明插件接入和通用流程，不宣传为真实共识协议验证。
- 通用英文资源新增 `discover`、`select`、`decompose`、`build_model` 和 `revise_analysis` 等任务模板，并测试最终动态渲染结果。

## 7. 执行顺序与阶段验收

| 阶段 | 实施内容 | 可检查结果 |
| --- | --- | --- |
| A | 调整类型、来源、材料扫描和知识包接口 | 同时表达规范依据、代码观察、冲突、候选目标和探索缺口；无固定目标注入 |
| B | 接通发现、选择、细化与真实/mock agent | 不输入具体目标即可形成有出处的候选、选择理由与实际代码绑定；失败有受阻记录 |
| C | 接通 agent 模型生成、TLC、预算和存储 | 不依赖投票模板的模型制品可以实际检查；正例、负例和启动错误语义区分 |
| D | 接通结构修订、实现测试、恢复与中文报告 | 工具结果返回所选目标/义务；历史失败保留；修订触发适用性检查 |
| E | CLI、架构检查、打包资源、非 Raft 样例与文档 | 安装后从任意目录使用；更换插件不修改核心；真实与模拟记录分开 |
| F | 执行真实无目标输入验收与固定回归 | 报告本次执行命令、日志、测试通过/跳过、工具结果和未完成条件 |

优先贯通 B 到 D 的最小纵向流程，再扩充异常测试，不先生成大量无实现接口。

## 8. 有限默认预算

初始建议：发现最多 5 个候选，最多读取 40 个文件片段，累计送入 agent 的材料不超过 120,000 字符；一次深入一个目标，最多 5 项义务，最多 8 次 agent 调用、3 次模型检查、2 次修订、1 次相同错误修订和1次反例重放。单动作默认 120 秒，总运行默认 900 秒，均可配置。

这些是执行上限，不是必须消耗的配额。不会为了凑候选数量虚构性质，也不会把边界外目标判为不存在。总预算必须覆盖探测、材料处理与实现测试，恢复继续累计已用预算；预算变化留记录。字符预算不冒充 token 或费用账单。

## 9. 验收分组

### 确定性框架回归

使用固定目标与 mock，覆盖状态转换、结构化输出校验、动态英文提示、引用合法性、预算、超时、工具缺失、认证和额度失败、进程清理、恢复、过期、原始仓库保护，以及正反例解析。增加“材料冲突导致待调查”“反馈新增目标或修改义务”“所选目标没有预置模板”的用例。

### 真实自主探索验收

输入只有仓库和配置，不包含选举安全性或其他性质。保存实际 agent 请求和响应，检查：

1. 候选目标有可定位材料和明确来源类别；规范依据不只来自代码行为。
2. 选择记录解释切入点与预算，并保留未选候选及未探索材料。
3. 义务与目标之间有解释，映射引用确实存在于本次快照。
4. 所选分析链能够进入真实模型检查，或产生具体、可恢复的受阻原因。
5. 真实结果经证据关联返回该目标/义务，报告保持原有范围与不确定性。
6. 至少一项反馈测试证明可以修订目标/义务集合，而不只是修改模型语法。

不断言 agent 必须选中某个固定目标，不匹配固定措辞。真实工具不可用时，上述真实验收标记未完成，mock 通过不能代替。
