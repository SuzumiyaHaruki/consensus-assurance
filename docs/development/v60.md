## HashiCorp 两组各一小时

用户已选择每组 `agent_calls=80`、`experiments=40`，`total_seconds=3600`、`agent_turn_timeout=900`、`action_timeout=600`。上限不要求用满，公共模板保持原预算和两项授权为 false。先生成两份本地忽略配置；以下代码仅在用户决定启动实验时执行。

```bash
cd /home/nitro/Desktop/consensus-assurance || exit 1
export PATH="$HOME/.local/bin:$HOME/go/pkg/mod/golang.org/toolchain@v0.0.1-go1.23.5.linux-amd64/bin:$PATH"

.venv/bin/python - <<'PY'
from pathlib import Path
import yaml
from consensus_assurance.cli import load_config
from consensus_assurance.core.config import Config

base = load_config('configs/targets/hashicorp_raft.yaml').model_dump(mode='json')
provider = load_config('configs/targets/deepseek.example.yaml').model_dump(mode='json')
for label in ('astra', 'deepseek'):
    data = dict(base)
    data['budget'] = dict(agent_calls=80, experiments=40, total_seconds=3600,
                          agent_turn_timeout=900, action_timeout=600)
    if label == 'deepseek':
        data.update(agent_model=provider['agent_model'],
                    codex_provider=provider['codex_provider'], agent_reasoning_effort='high')
    data.update(allow_agent_materials=True, allow_experiments=True)
    config = Config.model_validate(data)
    path = Path(f'configs/targets/hashicorp_raft.v60-{label}.run.yaml')
    path.write_text(yaml.safe_dump(config.model_dump(mode='json'), sort_keys=False))
    print(path, config.agent_model, config.agent_reasoning_effort, config.budget.model_dump())
PY

git -C /home/nitro/Desktop/hashicorp-raft rev-parse HEAD
git -C /home/nitro/Desktop/hashicorp-raft status --short
codex --version
go version
```

```bash
.venv/bin/consensus-assurance run --config configs/targets/hashicorp_raft.v60-astra.run.yaml --repo /home/nitro/Desktop/hashicorp-raft
```

核对结束原因后，再在相同环境运行 DeepSeek high；如果新开终端，先执行上面的 `cd` 和 `export PATH`。密钥只放环境变量，不写入文件或命令文本：
