# 以义务和证据为产物的 CFT 审计

核心术语只有 Activity、Behavior、Fact、Obligation、AuditQuestion、Evidence。实现理解帮助发现问题；审计结果包括有来源的候选解释、有边界的义务结论和证据，不是七类都标为理解完成。

```text
Target Profile：实际所有权、配置与边界
        ↓
七类 Activity 广度与反向源码表面核对
        ↓
描述性 discovery：不完整骨架，实际 Behavior → 产生/消费 Fact；保留 unknown
        ↕ 有界 Surface 扩展 / spec_refine 增量：按来源拆分、补充和纠正描述对象
受理不完整但一致的实现理解
        ↓
derive：结构化 AuditQuestion → 一个 Fact 生命周期与最小判别问题
        ↓
source review：局部源码、已有保护、明确未读范围
        ├─ 已解释：记录保护、适用范围和限制 → 下一候选
        ├─ 证据/适用合同不足且无明确下一核对：候选 blocked → 下一候选
        ├─ 选中描述有误：spec_refine → 重连同一 Fact / 生命周期
        ├─ 无关可复用描述遗漏：排队回流，当前候选仍可结束
        └─ 保证缺口仍在：一个主要 Obligation → 一个 AuditUnit
                ↓
        direct test / controlled schedule / local model
        ↓
Evidence → 有界结论与限制 → 回填理解 → 下一条高价值义务
        ↓
Consensus Audit Report：义务、证据、未决问题和限制
```

七类并列坐标分别关注决定形成与推进、权威和协议上下文转换、副本恢复与追赶、配置和参与者变化、决定应用、历史和恢复证据生命周期、客户端操作语义。它们不是流程阶段或互斥代码分区，也不构成数学完备性声明。无法归类的重要表面保留 UNCLASSIFIED_PROTOCOL_RESPONSIBILITY。

Behavior 是一个执行所有者在具体触发和上下文中的局部处理。不同 actor 或建立不同语义结果的分支先拆分。Fact 是指定身份和上下文中已建立的断言；观察、通知、请求转换与转换完成不能合并成一个“可能完成”的事实。生产者或消费者未知可以接受，但必须显式记录，不能跳过尚未理解的中间建立步骤。

Behavior 的 produces_fact_ids/consumes_fact_ids 是唯一权威边。反向索引和跨 Activity 关系由控制器派生，不再维护 Handoff 对象。ConsensusAuditSpec 仅包含 version、target_profile、activities、behaviors、facts、surfaces；Activity 不填事实清单或成熟度评分。

Obligation 是唯一正确性要求，可有其他义务作为依赖。AuditQuestion.importance 解释系统后果；当前单元只检查一个主要义务、一个主要事实及 establishment/preservation/consumption/recovery 中一种生命周期关系。候选、义务和当前检查须写清同一直接关系、必要前史、停止观察的位置及 excluded 后果；较广后果不能无意变成当前模型的完成条件。有依据的局部义务可以先检查，不要求人工预先证明失败历史。

字段修复只负责表示问题。描述错误和有来源的可复用遗漏通过 spec_refine 增量更新，旧版本与草稿保留；已受理义务单元引用的事实 meaning、identity 或 validity_context 改变，需要 F2 和显式问题重连。缺失来源和矛盾不能接受，明确记录的未知和外部依赖可以接受。调用完成不表示问题已解决。

优先执行已有的可靠检查，然后解决选中问题的决定性证据缺口和高后果未映射表面；普通 unknown 不自动产生无限补读任务。当前已知高价值义务有证据、已由保护解释或明确延期，并且没有悄悄忽略高后果表面时，才允许结束当前工作。预算耗尽也可以停止，未完成事项必须可见。

直接测试保留实际源码隔离执行、版本绑定、合法前史、身份/上下文关联、独立 oracle 和可观察适用性。模型按当前关系抽象必要状态及转移，说明省略过程保留了什么前提；影响终点的保护、锁、消息和错误路径不能被删去，性质不能作为行为 guard。条件入口只能回答局部执行问题；原义务若包含支持及先前决定，必须建立这些实际前史，或显式修订范围并保留原问题未决。

工作草稿、可搜索模型、模型结果和实现校准分别记录。未完成核心可以原地续写任务，但不成为可搜索模型；原生 Properties 不依赖 harness。SANY 通过只表示语法可用，TLC 只给出该有限模型的结果，实际轨迹校准仍须执行来源、合法前提及关联观测。局部赋值差异、原义务违反、第二次决定和应用后果需要各自的见证，不能互相替代。

义务形成前的问题沿用 AuditQuestion；QuestionCandidate 仅保存控制器状态、版本记录、读取回执引用及升级结果，不新增语义图。选中问题即可使用 depth，不依赖 AuditUnit 已存在。普通背景理解使用 breadth；两类预算与总上限保持不变。所有含 ReadRequest 的回复统一按实际用途预检唯一字符和区间成本。

部分读取保留 authored priority：首个不适配请求及后续请求延期。已有源码和延期回执进入同一候选的下一次分析；连续无新材料受既有 stagnation 上限约束，受阻候选保留而非抹除。当前问题结束后可在剩余调用/时间内选择其他 Fact/lifecycle。关闭候选不创建义务、模型、直接实验或性质证据；不能把“已有保护”意见写成协议正确。

已有候选完成源码核对后，`blocked + needs_specific_evidence` 表示证据不足延期，不是解释关闭或性质证据。保留来源、保护、未知和理由，并让出调度机会。升级一个候选不等于考虑完该版库存；已有单元优先，处置后处理相关描述反馈或选择另一真实问题。没有可操作问题时可明确 selection_exhausted；不能为凑数强造候选，也不能把有限停止当成覆盖证明。

AuditSpec 随源码获取逐步增长，不要求检查前枚举整个实现。Surface 的 mapped 只表示至少有一个源码支持的行为映射；deferred 是可见的未展开入口，不是错误。目录和声明不是语义证据。仅解释当前怀疑的保护论证留在候选；可被其他问题复用的执行者、分支、事实交接或权威边界才回流规格。不计算没有可靠分母的覆盖率。

### 当前工作集与历史分离

全局 AuditSpec 是持久知识，当前 packet 是选中问题的有限投影。方向概要和历史来源 ID 不等同于本次源码证据；仍须取得精确实现范围。候选每次返回完整的当前未决问题、相关反证和来源，旧版本完整进入 history，不再自动合并三字段。发现保护后可移除已解决疑点，但尚未解决的反证仍须保留。

合同归属不足且没有合理下一源码/检查，是 evidence_blocked；选中描述修正或诊断路径失败是 workflow_blocked；明确下一步受预算限制是 resource_blocked。三者从已有状态派生，不新增候选状态。no_issue_found 的 limitations 保存尚未执行及范围限制，不能仅凭这段文字制造语义争议；明确反证和未解决问题仍影响结论。离线回复及合成小模型只能验收框架链路，不能替代新自主实验。
