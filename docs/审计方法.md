# 审计方法

本项目使用 Codex 调查 CFT 共识实现。稳定的方法是选择性理解、因果调查和证据驱动修正；控制器承担结构、执行和证据边界，模型决定阅读顺序、调查粒度和下一步。当前运行时方法版本和加载路径以[权威清单](../src/consensus_assurance/resources/task-skills.json)为准。

## 整体与局部共同推进

决议形成与推进、上下文有效性与权威转换是互补的调查主线，用于提出正确性关系；恢复、配置与参与资格等支撑机制用于追踪实现责任，二者交织而不构成阶段或必填标签。从实际决定或已受理但尚未完成、取消或交接的责任出发，追踪依据的生产、条件变化与消费，寻找能改变判断的源码或观测。已有保护只解释其适用范围，新入口或上下文可以产生新的疑问。

可以在全局地图缺失或不完整时保存有来源的问题、阅读、探索，或者同时提交义务和完整检查。一个问题最少说明具体不确定性及捕获源码依据；后来通过 ID 更新相关字段。明确的源码解释可以结束局部疑点，无需补一个形式性测试。选择另一个问题不会自动暂停或关闭已有问题。

Behavior 记录实际条件行为，Fact 记录它建立的事实，Obligation 说明有适用依据的应有责任。可复用的 Behavior／Fact 保存来源、条件和修订；派生知识可用 knowledge 引用已有条目的明确版本和实际依赖的断言，不要求唯一主要 Fact 或全局地图。粒度应能区分影响调查的分支、持久化与发布、通知与完成、对象身份、成员资格及上下文变化。

## 因果调查与证据范围

条件观测只说明给定供给状态／输入时固定代码做了什么；局部合同违反需要真实许可该输入／初始状态的来源化合同、实际行为及匹配判据；可达协议违反需要一个共同合法前史产生必要参与者、状态、输入和上下文，并到达实际终点。私有处理器缺少保护、构造器接收预填存储或源码 TODO 都不能单独许可任意协议历史。终点较局部也不会取消它的调用前提；独立适用的公共接口合同则不必证明整个集群后果。

优先调用实际构造器、提案／消息生产者、存储和处理器，通过环境控制延迟、投递、计时、断连、允许的存储失败或重启。优先复用真实初始化前缀和目标测试工具；核对这些工具没有跳过待验证条件。持久快照仅能替代其合法来源和保留状态支持的前史，不能替代在途消息、请求身份或活跃工作。不能仅因序号相同而拼接两段不同历史。

自主审计期间禁止执行目标项目既有的完整测试集，包括未经筛选的整包／crate 测试；原生本地反馈和正式执行均适用。允许阅读测试、复用初始化和辅助函数，针对具体源码问题选择测试或构造包含多个案例的聚焦检查。必要构建和现有依赖编译仍遵守原权限、隔离和预算；这条规则不限制 CA 自身开发所需的回归验证。

合成状态、内部处理器和局部测试需保留测试供给的条件。明确前提由外部调用者、环境还是目标内部生产者建立；外部违规调用不能证明合法使用下的缺陷，合法使用中内部生产者违反前提则仍是目标责任。局部合同可以直接许可输入，不必构造集群。故障模型需要具体说明：允许的存储失败不同于修改已持久值；传输合同保证的 FIFO 不能以“延迟”名义任意重排。

发现条件异常后，优先延长或修正现有驱动，让真实初始化和生产者生成关键状态；不能只给同一合成状态再增加一个消费者。也可以证实外围保护、独立适用的局部合同，或暂停并写明具体判别条件。决定性观测先对应实际事件、对象和采样时点，再判断它支持哪项有来源的责任与后果；必要推理环节缺少依据时，保留已证行为，收窄主张或保留具体未决边界。活性需要继续工作的责任和允许调度，输出时间和场景标签不能代替实际事件与完成。

## 结果与修正

进程成功、实际观测和语义解释分别保存，不再合成 confirmed 确认标签。新实验报告直接使用英文问题与解释，模型缺陷主张不由比较或进程成功自动产生。正式检查固定源码、义务、判据、驱动、执行包／crate、版本及原始输出；必要前提未到达、身份不匹配或终点缺失时，即使程序成功退出也不能得出违反或满足。非零退出保留；仅当具体完成见证与独立失败的关系得到复核时，才可能保留范围内结果。

负面结果区分三种情况：构造、前提或测量失效，只撤去该见证的支持；有效实验未观察到后果，只说明已执行条件和观测范围；有来源的保护覆盖主张的适用范围，才支持该范围内的排除或收窄。不要求穷举条件或给每个负面结果补实验，源码可以直接说明保护范围。内部复核不是独立审计投票，必要前提不能通过“独立范围”消失，更广未测后果也不抹去独立成立的局部结果。

当前解释组织当前主张、决定性依据、重要反证和剩余边界。新证据改变前提时，替换依赖它的失效论证，并按实际来源、回执和使用关系修正知识；不能只在末尾追加撤回，也不能把另一执行的独立支持一并撤去。历史保存旧解释和逐次结果，同义复现可合并说明，目标是论证一致、条件完整，不是篇幅最短。最终缺陷有效性、CFT 相关性、去重和论文评分由人工离线判断。

执行后的驱动、判据、适用条件或义务变化使用同一个后继路径，保存前驱和实际差异，再执行、复核。仅纠正解释时可以复用已有来源和未变输入的执行。重复相同输入可以研究调度、测量或发生率等具体不确定性，保留每份回执与相反结果；次数和剩余预算本身不构成研究目的。发生率变化可以引出隐藏条件调查，但只有查明旧见证或必要前提失效，才否定其存在性依据。必要缺口按具体 gap ID 作答；引用执行时使用实际 CheckRun 与决定性事件索引，Agent 回合和其他复核不是经验观察。独立生产者探测须有显式关联及共同前史兼容性说明。

要求与判据属于固定实验，实际观察属于不可变执行，必要缺口在调查下登记并由解释明确作答。知识修订展示直接及经派生知识到达调查、实验和解释的版本化引用路径；只有模型明确标记的 affected_uses 进入原调查缺口处理，路径本身不代表结论失效。未改变陈述、条件或决定性依据的复现不必惯例式更新所有相关知识，但仍可补充有用引用。原实验和旧知识保持可读，解释修正不要求重跑。相同文字不代表相同责任或来源，控制器校验字节与关联，不能从文字证明任意可达性。

一份交接可以同时携带结果解释、相关知识更新和下一项就绪工作，最多请求一次新目标执行。复核或纯反馈之后，后续调用仍获得相关执行位置、当前缺口和简短解释，同一原生会话继续阅读和修正，不反复灌入全图。相同有效更新保留原始成本而不重复创建语义版本；反馈保留全局研究导航和执行定位，不额外展开已引用回执的局部问题，最新回执尚无解释引用时仍展示其所属问题。引用不等于问题已解决，缺口和完整解释仍可查；不以重复次数处罚或强迫造检查。

开放运行持续有用调查到总时间／调用边界或真实中断；正式执行额度耗尽后仍可进行有预算的源码工作。只有用户预设的有限定向任务能提前完成。到期保存已有工作，不再追加付费总结。新实验使用独立会话，不读取历史发现或本轮开发材料；目标源码只读，执行仅在隔离副本进行。
