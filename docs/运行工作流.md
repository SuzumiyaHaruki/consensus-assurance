# 当前运行工作流

## 选择、读取与继续

默认先按 Activity 组织理解，读取 Surface，恢复 Behavior / Fact，选择 AuditQuestion 并调查 Candidate；有据时才形成局部 Obligation。首次或候选处置后的选择，通过 selection_rationale 与一两个真实备选比较下一判别、额外理解和影响；没有备选就说明。普通“请求不保证完成”不是缺陷信号，续查不反复全库排名。

Paxos 配置显式设置 `agent_reasoning_effort: medium`，每次 Codex 分析调用通过 `-c 'model_reasoning_effort="medium"'` 覆盖全局推理强度。其他配置未设置该字段时沿用 Codex 自身配置。

新候选给出问题、范围、保护、未知项和精确来源请求。继续时明确使用 candidate_id；仅恢复暂停问题时可提交 candidate_id、audit_question=null 和理由，沿用原材料及下一步。分流提交 fork_from_candidate_id 和 fork_reason，新问题自行说明前提与来源。已解释的是具体假设，不能据此判定整个 Fact 正确；资源不足不会反复自动唤醒暂停候选。

候选升级不封住同版 Spec；完成已有可执行单元后仍能选择其他问题，只有显式 selection_exhausted 才标记当前库存有限停止。本地读取和 TLC 不消耗 Agent 调用；当前 build 可以使用最后一次调用，新候选与 Surface 调查仍需原有调用空间。删除旧外层预留，不提高总调用、时间或上下文上限；停止时报告具体单元、阶段和剩余资源。

读取次数硬配额已删除。material_chars/material_chunks 限制取得源行的并集，context_chars 限制实际 prompt；Agent 调用、总时间、执行与修复预算继续限制工作。路径或范围错误进入输入修复；容量不足留下普通延期回执，不要求模型反复改字段。每项任务显式附加需要的范围，共享缓存，不拼接跨任务收费计划。

这是预算策略变化：历史六次读取上限的运行原样保留，新版本不能声称与之完全同预算对照。回执可统计读取情况，但不承担收费状态。

## 反馈与检查

候选的终局解释、证据不足和义务升级必须有实际取得或附带的来源。source_ids=[] 只允许尚待精确阅读的初选或继续。代码保护、规范期待、测试断言与分析假设分开记录。

描述性反馈中，requires_recheck 及时修正当前判断；independent_enrichment 在候选处置或检查结果后合并相关意见、按最新规格处理，不阻塞就绪检查。包中明确哪些有来源的认识尚未回填，已被更新涵盖的意见可以返回空 delta，不再追加过期判断调用。意见合并不表示语义相同，候选假设和模型初态不能因此成为 Fact。

直接检查接纳一份计划，然后在隔离副本执行。整体审阅使用现有 semantic_review 入口，包含当前义务、实际调用、前提、事件和唯一性质定义。存在实质问题时才补读或修订；没有逐 claim/binding/relation/unit 的常规审批等待。原始比较 outcome 不由复核状态覆盖，最终 confirmed 受来源、合法性、未知与反证限制。

F1 修改行为、映射或环境；F2 有据修订性质及适用含义；F3 增加真实生产者、过滤者或边界支持；F4 修复实验前提。技术修复保留 Properties 和共同性质。非零退出或 panic 不自动确认为缺陷，也不自动要求修好 harness 以消除异常。

ModelDraft 使用原生 Properties 模块；自动 marker 仅适用于具有真实 observation 的完整 Bundle，其生成器不支持 reference 字段比较。源码足够但核心未组合完成时，保存原始草稿和 pending_work，继续同一 build；未受理错误带完整原稿、具体错误、义务、源码续写，不走窄字段 OutputRepair。续写沿用修复次数、停滞、总调用与时间上限，半成品不注册为可搜索模型。

核心完成后，即使没有执行后端，也可保存 model_only，执行真实 SANY 和 TLC；语法错误进入已有 technical 任务。只缺 harness / observation 时保留未校准搜索，再按能力补装配、实际执行和校准。工具缺失、权限或超时不交给模型猜改。完整 Bundle 可沿用已有直接执行路线，不强制先拆成草稿。

no_issue_found 的纯执行限制不自动变成 issue、disputed 或重复阅读任务；真实反证和明确争议仍保留。新增评语或无关材料不会唤醒同一失败草稿。当前范围修订仍走既有显式路径，接受过的性质不能借技术修复改写。

## 来源与保存

来源由文件版本及精确闭区间确定；相邻已取得区间可以合并，不能跨未读洞或版本拼接。已缓存、当前发送和历史引用是不同事实。ask 是包准备的唯一入口；初选有库存导航，建模包保留选中 Fact、义务与范围、必要源码、当前草稿及未决反证，不重复铺开 Activity / Surface 库存和已解决评语。完整 Spec、回复和审阅留在归档；发送前超限仍保留真实阻塞，不消耗 Agent 调用。

图修订沿用实际字段差异、版本及现有 commit_graph。普通读取只更新材料与回执。状态在完整回复接受、执行结果保存、暂停和结束等节点落盘；派生视图在结束或报告时导出。

当前 manifest 版本为 model-continuation-v10。运行恢复使用自身源码副本；已完成昂贵调用按实际输入复用，未完成执行保留未知。旧框架归档只读，不能在原目录跨版本续跑；离线定向子目录须标明导入材料、人工改动和独立用量，不把受控结果归给原实验。

原目标与历史实验保持只读，不发送未授权材料、不启动未经请求的付费审计或发布。归档删除仍须明确授权，旧失败不能改写成成功。人工定向、模拟回复和真实执行分别记录。
