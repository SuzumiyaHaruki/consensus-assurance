# 扩展接入

## 新实现

实现 `ports/interfaces.py` 中的 `ImplementationAdapter`：仓库识别、工具版本命令、能力探测命令、实验命令、harness 类型与固定目标文件名。只返回 adapter 组织的 argv，不执行模型返回的 shell 文本。把适配器加入入口 `registry.IMPLEMENTATIONS`，配置选择其名称。

材料阅读和 G—O—C 建图由同一工作流与 agent 执行；不要在实现 adapter 中固定返回目标、模型或结论。snapshot 不再按 Go/Python 后缀决定执行副本。适配器可提供 `required_inputs(repo)` 声明必需资源，以及 `symbol_hints(file, lines)` 提供实际符号提示；通用层负责安全筛选和来源记录。必要的语言构建和事件控制仍属于实现接入层。

## 协议知识

增加协议目录和 `knowledge()` 资源读取函数，提供有出处的术语、候选关系和调查方法，并注册 `KNOWLEDGE`。知识不是已证事实。默认使用 `protocol: none`；显式 `protocol: raft` 等配置仅添加参考材料，不改变工作流。不得导入 Codex 或把某个法定人数规则变成通用核心字段。

## Agent 后端

实现 `probe` 与 `analyze`，输入是英文任务和本阶段 response schema，输出是实际 `CheckRun` 与通过校验的结构化对象。必须保存原始响应、实际版本和阻塞原因。不可用时不切换收费后端、不调用隐藏 mock。

真实 Codex 适配器根据 `exec --help` 检查 sandbox、schema、输出文件和 ephemeral 等标志，使用原有配置和认证；不读取凭据。本次开发的材料发送权限被用户关闭，因此只验证本地能力探测及模拟错误处理，没有运行真实语义分析。

## 验证后端

实现 `probe`、`check` 和 `calibrate`。`CheckRun.outcome` 与进程退出状态分开，证据引用模型、快照和所有相关制品。轨迹校准必须有可执行语义，不能换成 agent 评分。注册 `VERIFIERS` 即可，核心不识别 TLC 专属输出。

## 事件映射

当前 observation schema 使用 `{model_field, raw_field, source}` 项，source 为 state、event 或 metadata，支持标量字段投影。模型 `Obs` 的字段必须与投影一致。不同投影规则需要扩展一个可执行转换器并保存转换版本；不允许用任意 agent 表达式直接执行 Python。

增加测试时分别标记：预设回归、mock 流程、真实工具、真实自主分析。非 Raft 夹具仅证明可复用接入，不代表已验证另一真实共识协议。

## 结构化输出与监测扩展

Codex 的严格 wire schema 将开放字典表达为 `{key, value_json}` 条目数组，回传后恢复原始 JSON 值；非空参数不会被静默清空。原始响应与校验错误保存。扩展 backend 时复用 wire_value 或明确实现等价编码，不应通过删字段取得 schema 通过。

新 checker 必须显式关联主张和范围。事件监测器当前仅支持标量 eq/ne 条件；若扩展其他监测语义，需要可执行实现与独立测试，不能把任意 agent 表达式交给 eval。合法 TLA EXCEPT 更新与字符串/注释中的符号不被视为宿主调用；不受控模块和宿主覆盖仍禁止。
