## 当前实现与职责退出

默认方法采用 A1/A2 两个核心、A3–A7 五类支撑，唯一角色映射在 `core/types.py::ACTIVITY_ROLES`。正式问题必须把核心关系落实到实际 Behavior／Fact 和来源；`supporting_behavior_ids` 单独保存非直接邻居的前史、上下文及后果支撑。`activity_focus` 只约束本次子方向，不再负责开启核心定位。

原生 `model` 只提交最小 ModelDraft，按需搜索历史、检查独立 Properties 与可达性；形成义务前归属 Candidate 或 Surface，不创建占位 Unit／claim。实现证据统一使用现有 `check/revise_check`。删除原生 Bundle 装配、自动模型实验／校准／重放归因分支、重复 `assess_execution`、`validate_feedback` 预演和 F1/F4 Feedback 分支；F1 由模型修订承担，F4 由直接检查修订承担。离线 Bundle、TLC 校准与轨迹工具仍可显式使用，它们不能自动确认实现。旧阶段里程碑的重复推导退出，原始操作和工具时间戳继续保留。

研究反馈只用一次 `feedback.answered` 及来源关系解释当前未知／反证的变化，旧问题留在 history。执行、复核和已受理决定可沿所属对象追溯来源；未知 ID 仍拒绝。地图、Candidate、F2/F3 组合提交统一填写当前基准版本，控制器只归一化版本元数据；它不能补写未声明的语义变化。无关消费者增补不使旧局部结果失效，新增 producer／失效路径仍须说明影响并按实际范围走 F2/F3。删除全局 `feedback_due` 和精确复填 `deferred_work` 的合同。

资源、用户和工具停止先保存原稿、真实待办、剩余额度及诊断，不接受随附语义修改。正常完成仍检查范围和未完成工作。恢复优先处理已有回执和已受理制品，零 Agent 余额不阻断预算内的本地执行。报告和 Agent 索引使用同一当前投影，不重复嵌入每版地图、历史反馈、Unit 问题或探索 harness；完整材料仍在 state 和制品路径。

证据语义先判断独立适用性，再关联身份／前提，最后判断 alias 条件和完整结果。`witness_complete` 表示至少一个有效有限违反见证，`comparison_complete` 表示当前比较范围完整。独立操作缺失可以与有效 witness 共存；同一见证缺失、歧义和可能跨操作的解析损坏仍阻止确认。局部见证不自动使 Unit checked，也不提升成更广后果。事件索引、身份、缺失字段和争议来源进入报告。

```python
import json, subprocess
from pathlib import Path
base = 'c5a5c33098b709c4e11779c9bbf3993c77fbe52a'
def git(*args): return subprocess.check_output(['git', *args])
def group(p):
    if p.startswith(('src/', 'scripts/')) and p.endswith(('.py', '.go', '.sh', '.tla')): return 'production'
    if (p.startswith('src/') and ('/resources/' in p or '/plugins/protocols/' in p)) or p.startswith('configs/') or p == 'pyproject.toml': return 'resources'
    if p.startswith(('tests/', 'docs/')) or p in ('README.md', 'AGENTS.md'): return 'tests_docs'
def count(paths, read):
    result = {}
    for p in paths:
        k = group(p)
        if not k: continue
        data = read(p)
        row = result.setdefault(k, [0, 0, 0])
        row[0] += 1
        row[1] += sum(bool(line.strip()) for line in data.splitlines())
        row[2] += len(data)
    return result
old = git('ls-tree', '-r', '-z', '--name-only', base).decode().split('\0')
new = [p for p in git('ls-files', '-z', '--cached', '--others', '--exclude-standard').decode().split('\0') if Path(p).is_file()]
print(json.dumps({'baseline': count(old, lambda p: git('show', base + ':' + p)),
                  'current': count(new, lambda p: Path(p).read_bytes())}, indent=2))
```
