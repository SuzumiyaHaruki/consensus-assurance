# 当前限制与未完成验收

- 系统只有一条领域引导、实现为据的流程；没有消除或验证 LLM 预训练知识。协议知识不是适用性证明。
- 本轮没有启动 Hashicorp 真实自主链，也没有通过运行时 agent 发送其材料。Codex wire schema 的非空参数兼容已本地测试，真实后端接受情况及分析质量仍待用户确认后的实验。
- Grounding、引用和版本检查只能约束证据结构，不能自动证明自然语言推导正确。文档、测试和代码职责都可能解释错误；争议未决时不升级缺陷。
- 局部模型仍是有限候选抽象，不从安全性搜索推断活性、公平性或最终同步。TLC 完整搜索没有反例仅支持实际配置 checker 的范围。
- 校准是有限观测可达性。允许的内部步数和投影可能过窄或过宽；部分观测能匹配好坏两条路径时，不能由其中坏路径确认实现违反。
- 实现级确认目前限于共享描述生成的事件蕴含断言及完整观测的跨事件支持一致性，且需要已关联的前提、合法性条件、适用性材料与代码绑定。不支持任意 TLA 性质的自动监测，也不自动证明插桩没有遗漏。正常退出的受控样例已检验可确认路径；复杂进程崩溃、磁盘故障和异步控制仍需具体 harness。
- 定向补读有独立轮数和累计材料预算，仅基于实际 catalogue/文件范围。找不到生产者或补读后仍不能建立关系时保留缺口，不无限扩大上下文或编造函数。
- 默认 bubblewrap 隔离可写副本并隐藏主目录，保留网络命名空间；不是网络隔离。`allow_experiments: false` 同时禁止能力测试、校准实验和重放，仅可做不执行目标代码的版本探测。
- 授权执行副本保留安全允许的构建资源，包括非文本文件；敏感、符号链接、过大或指令文件有排除记录。适配器必须声明关键必需输入；无法自动推断任意构建系统的全部隐式资源。过滤无法识别所有未知格式的秘密。
- 新图更新保留旧对象版本。F3 历史范围不能用于新范围，F4 不使旧模型搜索失效；外部完整快照/配置改变时仍会停止并要求新运行，没有跨快照自动合并证明。
- 中断后的未知执行会明确记为 outcome_unknown，并在预算内重试原阶段；这适用于受控副本中的可重复动作，不承诺外部服务副作用的恰好一次语义。
- 本轮合成契约和关系夹具不是 MongoDB/Hashicorp 的真实缺陷、不是生产共识协议验收，也没有形成方法优越性结论。


历史第三轮规则与取舍见 [第三轮审计修订与验收](第三轮审计修订与验收.md)：包括受限共享性质监测、跨事件历史、局部输出修补、逐义务进度及模型提交恢复。当前接口及验收以当前代码和第五轮说明为准。


第四轮增加职责探索和语义复核任务队列，具体调度、F2 语义对象修订及限制见 [第四轮覆盖与语义复核](第四轮覆盖与语义复核.md)。第三轮说明仍对应局部证据链机制；当前默认流程不再以一次 discovery 的清单作为全部分析边界。

## 第五轮的实际边界

- 字段 diff、版本及证据关联检查不能自动证明语义推导正确。明确的复核依据和解决关联可以消除已处理的限制，agent 的一致意见不等于独立证明。
- 触发检查只支持 Behavior 中命名的无参数状态谓词。历史条件需由当前实现有据地建模成状态；不提供任意时序性质的非空洞性证明，也不默认加入崩溃、节点或轮次假设。
- 文本等价但写法不同的模型可能保守地重新检查；没有 SMT 等价证明。纯 harness 修改可显式复用相同语义输入的搜索，不能复用原实验的确认。
- 交接覆盖声明仍需复核；存在 binding、事件名或两端 goal 不表示保证已经成立。实现确认仅支持现有有限观测性质类，单点观测不代表集群目标可观测。
- 后果规划有独立上限，可能只留下 O 层结果。补偿机制只能在有实际材料、检查与适用依据后用于修订后果判断，不能为得到 G 违反删掉真实防护。
- 预算估算是任务调用数下限，不是精确时长、token 或费用预测。探索、复核和建模共享原有 agent_calls；默认不自动提高付费上限。

真实 HashiCorp 新实验仍待用户检查本轮代码并授权。受控样例和 mock 调度测试不计作自主审计验收。
