# 首版限制

- 本次用户不授权发送仓库材料，真实 Codex 自主发现、真实模型/harness 生成和真实语义反馈均未验收。产品入口和适配器已经实现，不能因此宣称自动分析效果已成立。
- 模型为有限范围的候选实现抽象。当前检查目标以状态安全性不变量为主，不验证活性、公平性或最终同步。
- TLC 校准检查有限观测序列的可达性，不证明实现与模型等价。当前只支持标量直接投影，内部动作必须不改变 Obs，并有有限步数限制；过小的步数限制也可能导致不兼容，需要 F1 分析而非直接认定实现出错。
- 默认实验使用 bubblewrap 限定可写副本并隐藏主目录，保留网络命名空间；不声称网络隔离或可防御任意恶意宿主代码。框架不接受任意 shell 命令。应只运行已授权目标和环境中的实验。
- Go 模块使用本地缓存，不自动下载。现有测试探测只覆盖具体选中测试；精确异步控制、进程崩溃和磁盘故障能力必须由实验建立，不能由工具安装状态推断。
- F3 当前可沿已存在的具体关系及绑定扩展；尚未读取的上游代码需要新的材料/关系，无法完成时保留缺口。首版未实现无限递归的仓库搜索。
- F2 会保守地把旧证据和校准标记需重验。恢复检查输入不一致时停止并要求新运行，没有自动合并跨代码快照的发现。
- 反例实验可以记录前提顺序及实际观察，但不会只依据 agent 断言或生成 harness 的断言把发现升级为实现义务/目标违反。完整合法性审查和一般化模型轨迹到代码调度的转换仍是工程缺口。
- 事件顺序检查依赖真实插桩日志和观测设计，不能自动保证观测点准确。生产存储语义未被接口完全约束；本地投票回归只检查条件化的写入与内存状态重建。
- 材料筛选排除凭据文件、符号链接、大文件和已识别敏感内容；不能保证任意源文件中都不存在未知格式的秘密。材料发送受显式配置控制，本次关闭。
- 不提供整体正确性分数、完整证明演算、分布式调度或研究优越性结论。
