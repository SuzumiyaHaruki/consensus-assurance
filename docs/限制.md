# 能力限制与证据边界

- 自主发现不保证目标或义务完整；职责概览和候选数量不是全系统覆盖率，也不是共识协议正确性证明。
- Grounding、版本和引用检查约束证据结构，不能自动证明自然语言解释或契约判断正确。冲突、反证和未确认前提必须保留。
- 局部有限模型不能证明未建模规模的实现，也不能从安全性搜索推断活性、公平性或最终同步。所有范围缩减必须说明。
- TLC 性质搜索、触发可达性、真实轨迹兼容和实现违反是不同结论。缺少同一操作/对象/上下文的实际观测时不能确认实现缺陷。
- Go/Python 的定位器是有限的声明索引，不是通用 AST/类型解析平台。跨片段声明、复杂语法及调用身份仍可能受阻；不能用任意字符串匹配绕过来源检查。
- 修复可以纠正来源/方面元数据或保全拆分未接受绑定，但不能删负面判断、困难路径、性质或故障分支来获得通过。复杂混合语义变更仍需范围调查或 F2。
- 材料缓存、当前发送范围、历史证据与显式引用分别处理。当前上下文规划和历史复核压缩仍不完善；已读不代表每次任务都收到，超限也不保证能自动分解。
- 配额按实际工作记录，不保证每个预算配置都能完成模型。缓存重附加仍消耗模型调用和时间；重复无进展会停止。不得将字符估算换算成精确 token 或费用。
- 单次动作超时上限受剩余总时长限制。修改单动作上限不能恢复耗尽的总预算，控制器版本或输入变化也不能直接复用旧运行。
- Snapshot/LogStore 等接口成功返回不自动代表任意具体后端已完成物理持久化。内存测试替身、弃置存储和生产磁盘契约不能互相替代。
- 默认 bubblewrap 隐藏用户主目录并限制工作副本写入，但目前保留网络命名空间。较弱 workspace 模式不等同于安全沙箱，系统不自动降级。
- Codex 认证、网络、额度及版本能力可能使真实调用受阻；不读取凭据、不切换收费渠道，不用 mock 补造真实执行。
- 受控样例和录制回复只验证所测机制，不能替代新的真实自主分析。当前实际状态以所保留运行的原始报告为准，尚未完成真实目标的自主建模验证闭环验收。

具体使用见 [运行工作流](运行工作流.md)及 [环境要求](环境要求.md)。


当前补充边界：源码定位仍是有限 Python/Go 词法/语法定位，不是通用类型解析；不能跨未读洞或内容版本拼接。条件 ID 解决关联和修复歧义，不能自动证明“残余限制与原问题独立”。当前语义视图保留相关未解决反证，过多必要信息仍可能超限，需要缩小有据的任务，不能无限压缩。

模型先保存只改善产物交接。没有真实 harness/观测的结果仍是模型层；核心行为缺资料的草稿不能执行。性质编码修正沿已有对应性复核路径，普通技术修复不能改弱 Properties。受控样例的预定响应与实际 TLC 可证明框架路径，不能预测新的 LLM 一定生成正确模型，更不能证明 HashiCorp 没有漏洞。

七类规格是描述性理解，不保证发现全部正确性责任。未分类项必须显式报告。当前已选 Fact 的 meaning/identity/validity_context 不能在普通规格修订中改变；需先通过有来源的规范修订处理受影响问题。运行使用固定预算；源码不足、不可控调度和无可靠 oracle 都应保留为未决。
