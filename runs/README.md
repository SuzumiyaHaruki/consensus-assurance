- 先存储再回复：leader 消费回复时，提交与 follower Match 均到索引 3，follower 的 MemoryStorage 也已到 3。
- 先回复再写同批 Entries：leader 消费回复时，提交与 Match 已到 3，而 follower 的 MemoryStorage 仍到 2；固定调度点完成延迟写入后，存储到 3。

探索选取 follower HardState 不变的批次、有限延迟另一个 follower，并以 MemoryStorage 代替真实磁盘。它说明早发回复策略会产生可观察影响；该策略是否得到适用接口约定允许仍有冲突，没有执行崩溃或永久数据丢失，也没有建立实现违反或更广泛共识后果。第 4 轮在回流这些观察之前被网络超时打断，具体边界见[受理的探索说明](2026-10-02_13-39-40-etcd_raft-real-run/submissions/3854ee3424c44026a90020058c74994f/accepted.json)。
